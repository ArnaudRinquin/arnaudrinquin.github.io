Before side projects came with a chat window, I published small tools whenever something annoyed me. Some found an audience. GitHub archived them in the 2020 Arctic Code Vault.

- [react-native-radio-buttons](https://github.com/ArnaudRinquin/react-native-radio-buttons) (410★, 57k downloads): radio-button logic for early React Native. Now deprecated.
- [local_modules_poc](https://github.com/ArnaudRinquin/local_modules_poc) (93★): a proof of concept for structuring big Node apps with `local_modules`.
- [redux-reroute](https://github.com/ArnaudRinquin/redux-reroute) (80★): location reducer and routing helpers for Redux.
- [atom-zentabs](https://github.com/ArnaudRinquin/atom-zentabs) (49★): keeps the number of open tabs in the Atom editor below sanity.
- [darkest-companion](https://arnaud.rocks/darkest-companion/) (29★): curios and provisions helper for Darkest Dungeon.
- [rm-local-modules](https://github.com/ArnaudRinquin/rm-local-modules) (31k downloads) and [babel-plugin-discard-module-references](https://github.com/ArnaudRinquin/babel-plugin-discard-module-references) (26k downloads): small build-tool helpers.
